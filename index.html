Como pegar sua API Key (grátis)

  1. Acesse aistudio.google.com/apikey
  2. Faça login com sua conta Google
  3. Clique em Create API key (ou “Criar chave de API”)
  4. Escolha um projeto (ou crie um novo) e confirme
  5. Copie a chave gerada e cole no campo abaixo
